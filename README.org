* About

This is a major mode for Emacs to support editing Structurizr DSL files. It is based on [[https://github.com/josteink/tree-sitter-structurizr][Structurizr treesitter]] and provides also support for Eglot by integrating [[https://gitlab.com/systemticks/c4-dsl-language-server][C4 DSL Language Server]].

* Usage

The most basic configuration to use this mode would be something like the following:

#+begin_src emacs-lisp
(use-package structurizr
  :mode ("\\.dsl\\'" . structurizr-mode))
#+end_src

The first time you enter =structurizr-mode=, it will ask you to install the [[https://github.com/josteink/tree-sitter-structurizr][Structurizr Treesitter Grammar library]].

If you want, in addition, to use Eglot you will have to install the [[https://gitlab.com/systemticks/c4-dsl-language-server][C4 DSL Language Server]]. After installing it you will have to customize (M-x customize-variable) the variable =structurizr-language-server-path=, in order to point to the =c4-language-server= executable.

Eglot might fail to start sometimes, due to a startup issue syncrhonization issue, and all you have to do is retry (i.e. rerun the =eglot= command).
